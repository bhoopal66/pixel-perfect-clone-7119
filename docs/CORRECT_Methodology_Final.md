## 🎯 CORRECT DEFINITIONS (USE THESE!)

### 1. **Turnover = Total Credits**
```
Turnover = Sum of ALL credit transactions from bank statement
```
- **NO exclusions** for cash deposits
- **NO exclusions** for sister concerns
- **SIMPLE:** Just add up all credits

### 2. **Average Balance = Average of EOD Balances**
```
Average Balance = Sum of all EOD balances / Number of days
```
- EOD = End of Day balance
- Use daily closing balances
- Average across the period

### 3. **Average Balance % of Turnover**
```
Avg Balance % = (Average Balance / Turnover) × 100
```
- Shows how many times the balance covers turnover
- Higher % = stronger liquidity position
- Calculate for: Monthly, Quarterly, H1, H2, Yearly
